# SmartPark HR Management System

A modern Human Resources Management System built with React and Vite for managing employees, departments, salaries, and HR operations.

## Name and Description

**SmartPark HR Management System** is a full-stack HR and payroll management application designed to help organizations manage departments, employees, salaries, and administrative workflows efficiently.

## Overview

This frontend application provides an interactive dashboard and user interface for the SmartPark HR management system. It allows administrators to:

- View dashboard summaries
- Manage employees
- Manage departments
- Process payroll and salary records
- Generate reports

## Features

- Responsive dashboard
- Employee management interface
- Department management interface
- Salary and payroll processing UI
- Authentication screens
- PDF reporting support

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- React PDF

## Prerequisites

- Node.js (v18 or newer)

## Installation

```bash
npm install
```

## Environment Variables

No additional frontend environment variables are required for the default setup.

## Running the Application

```bash
npm run dev
```

The app will be available at http://localhost:5173

## Build

```bash
npm run build
```
